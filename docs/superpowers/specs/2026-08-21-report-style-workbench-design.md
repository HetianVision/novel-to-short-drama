# 报告风格短剧工作台视觉重设计规格

日期：2026-08-21

状态：待用户审阅

适用仓库：`HetianVision/novel-to-short-drama`

## 1. 目标与边界

将本地工作台的视觉语言改为与 `shuohao-skills` 六个 Skill 的 report 页面一致，同时保留工作台已有的项目管理、资料上传、Skill 任务调用、任务日志、成果物预览和视频任务功能。

本次是工作台展示层重设计，不修改以下内容：

- `skills/` 下任何 Skill、脚本、规则、报告模板和锁定快照；
- 工作流阶段顺序、任务输入输出契约和 API 路由；
- 项目产物目录、任务状态机、Provider 适配逻辑；
- report HTML 内部的渲染样式。

工作台只借鉴 report 的视觉语法，不把 report 页面误做成工作台本身。

## 2. 视觉基线

### 2.1 配色

沿用原 report 的冷灰印张体系，不保留当前深色工作台的主视觉：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#eceded` | 页面底色、报告画布外层 |
| `--panel` | `#f5f6f5` | 内容面板、卡片、预览外框 |
| `--side` | `#e4e6e3` | 项目与工作流侧栏 |
| `--ink` | `#191d21` | 标题与正文 |
| `--muted` | `#68706e` | 辅助说明、元数据 |
| `--rule` | `#cfd2cf` | 细分隔线、表格线 |
| `--seal` | `#8a3324` | 当前选中、执行动作、原文/重点标记 |
| `--seal-2` | `#c56a4e` | 次级提示、活动状态 |
| `--ok` | `#3d6b4f` | 成功、通过、已完成 |
| `--danger` | `#9d3e35` | 失败、不可执行 |

铁锈红只用于当前状态、重要动作和质量相关信息，不作为所有按钮的通用装饰色。

### 2.2 字体

- 叙事/报告标题：系统宋体，如 `Songti SC`、`Noto Serif SC`；
- 工作台界面和操作文案：系统无衬线字体；
- 阶段编号、任务编号、提示词和文件路径：系统等宽字体；
- 不引入外部字体，保证本地运行和离线报告预览不依赖网络。

### 2.3 形态

- 页面以细线和留白分区，不使用当前的大面积深色渐变；
- 卡片保持轻边界，默认无厚阴影、无大圆角；
- 结构编号只出现在真实工作流顺序和报告区块标题中；
- 动效只保留状态变化和加载反馈，避免装饰性漂浮动画；
- 空状态必须给出下一步动作，不使用纯装饰符号。

## 3. 工作台布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ 项目名 · 工作台页眉 · 当前阶段 · 成果物数量 · Skill 锁状态           │
├────────────────┬──────────────────────────────────┬──────────────────┤
│ 项目与输入资料  │ 成果物报告画布                   │ 运行记录          │
│ 01 工作流       │ 项目输出目录                     │ 当前任务          │
│ 02 角色         │ JSON / Markdown / HTML / 图片    │ 状态与事件        │
│ 03 美术         │                                  │ 重试 / 取消        │
│ ...             │                                  │                  │
└────────────────┴──────────────────────────────────┴──────────────────┘
```

### 3.1 页眉

- 使用 report 页面的细黑线页眉结构；
- 左侧显示项目名或“短剧制作工作台”，不再使用旋转方框字标；
- 中部显示当前项目的阶段摘要；
- 右侧显示本地服务、Skill 锁、成果物数等状态；
- 低频操作（刷新、Skill 更新检查）使用轻量文字按钮。

### 3.2 左侧工作流栏

- 背景使用 `--side`，与 report 角色页的侧栏同源；
- 项目切换、资料上传、工作流阶段、Skill 版本检查按垂直目录排列；
- 阶段沿用 `01`—`06` 编号，使用细线连接，当前阶段使用铁锈红边线，完成阶段使用绿色状态；
- 阶段按钮显示明确动词：生成大纲、生成角色、生成美术、生成剧本、生成分镜、生成图片；
- 禁用阶段要说明缺少的上游产物，不仅降低透明度。

### 3.3 中央成果物区域

- 顶部为 report 风格的标题、统计指标和成果物类型筛选；
- 成果物目录采用轻量列表，不使用深色选中块；
- 预览面板以白色纸张为主，报告 HTML 使用足够的高度和宽度；
- JSON、Markdown 使用等宽内容区；图片和视频使用浅灰画布居中展示；
- “创建视频任务”放在成果物工具栏，只有存在合格分镜投产包时启用；
- 空状态显示一条 Iconsax 图标、说明和下一步动作，不显示 `◇`、`◌` 等字符。

### 3.4 右侧运行记录

- 使用 report 的检查单/元数据风格，而非终端黑底；
- 任务列表显示阶段、状态、开始时间和产物数量；
- 任务详情显示状态、Skill、任务编号、输入摘要和事件流；
- 重试、取消、刷新均使用图标 + 文字，图标不单独承担语义；
- 错误信息使用明确的动作建议，禁止只显示“失败”或空白状态。

## 4. Iconsax 图标规范

### 4.1 来源与交付方式

- 所有界面图标来自 Iconsax 免费图标集合；
- 图标以本地 SVG 方式随工作台交付，禁止运行时依赖外部 CDN 或远程图标字体；
- SVG 使用统一的线性风格，默认 `1.5px` 描边，颜色由当前语义状态控制；
- 图标必须有 `aria-hidden="true"`，按钮必须有可见文字或 `aria-label`。

### 4.2 图标映射

| 场景 | Iconsax 图标方向 |
| --- | --- |
| 新建项目 | `folder-add` |
| 上传小说/资料 | `document-upload` |
| 项目/目录 | `folder-2`、`folder-open` |
| 报告/JSON/Markdown | `document-text` |
| 图片 | `gallery` |
| 视频 | `video-play` |
| 执行任务 | `play-circle` |
| 已完成 | `tick-circle` |
| 运行中 | `timer-1` |
| 刷新 | `refresh-2` |
| 重试 | `rotate-right` |
| 取消/关闭 | `close-circle` |
| 查看详情 | `arrow-right-2` |
| 搜索或筛选 | `search-normal-1`、`filter` |

具体 SVG 文件名以 Iconsax 免费图标库实际导出的名称为准，但不得用 emoji、Unicode 图形字符或自绘替代图标。

### 4.3 禁止项

工作台 HTML、CSS 和 JavaScript 中不再出现作为图标使用的以下类型：

- emoji；
- `＋`、`↥`、`◇`、`◌`、`∿` 等 Unicode 装饰/动作字符；
- 旋转方框字标、字符箭头和字符状态点；
- 只靠图标、不带可理解文字的主要操作按钮。

## 5. 交互与数据约束

只改变展示层，保留现有行为：

- 项目创建、资料上传和项目切换继续走现有 API；
- 六个 Skill 阶段和原有解锁条件不变；
- 成果物筛选、预览、任务 SSE、取消、重试不变；
- Provider 选择和视频任务创建不变；
- `skills/` 保持只读，不能因视觉重构被修改。

响应式规则：

- 宽屏优先，中央成果物区域获得最大宽度；
- 中等宽度时右侧运行记录下移为第二信息区；
- 手机宽度时依次显示页眉、项目/输入、工作流、成果物、运行记录；
- 键盘焦点清晰可见；
- `prefers-reduced-motion` 下关闭非必要动效。

## 6. 实现边界

预计修改：

- `workbench/public/index.html`：去除字符图标、补充图标容器和语义标签；
- `workbench/public/styles.css`：重建颜色 token、布局、面板、状态和响应式样式；
- `workbench/public/app.js`：统一 Iconsax 图标渲染、必要的状态图标和空状态文案；
- `workbench/public/icons/`：新增本地 Iconsax SVG 资产；
- `workbench/tests/ui-smoke.test.mjs`：增加图标来源和禁止 emoji/字符图标的结构检查。

明确不修改：

- `skills/`；
- `skills.lock.json`；
- `workbench/server.mjs` 和现有 API，除非浏览器验证发现与视觉改造直接相关的展示接口缺陷；
- report Skill 的生成器和 `report.webp` 资产。

## 7. 验收标准

### 7.1 视觉验收

- 空项目页面与原 report 的冷灰印张、铁锈红、细线、宋体标题和轻卡片语言一致；
- 有项目页面中的成果物预览成为视觉中心；
- 不再出现深色渐变主背景、厚阴影、旋转字标和字符图标；
- 1440px 左右视口下项目、工作流、成果物、运行记录均可辨识；
- 缩小到移动宽度后不出现横向滚动或内容重叠。

### 7.2 功能验收

- 原有 UI smoke、API 测试和基准测试继续通过；
- 可创建项目、上传资料、触发至少一个任务并看到状态变化；
- 成果物筛选、HTML/JSON/Markdown/图片/视频预览继续可用；
- Iconsax 图标文件由本地服务提供，页面不请求远程字体或远程图标资源；
- HTML/JS/CSS 不包含 emoji 和被禁止的字符图标；
- `skills/` 的内容和哈希保持不变。

### 7.3 浏览器验证

至少复核以下状态截图：

1. 空项目初始页；
2. 已创建项目、等待上传资料页；
3. 有成果物和运行任务的页；
4. 报告 HTML 预览页；
5. 移动宽度响应式页。
