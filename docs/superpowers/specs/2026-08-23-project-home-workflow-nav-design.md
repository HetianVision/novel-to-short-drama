# 短剧工作台首页与顶栏工作流设计规格

## 目标

把当前单页三栏工作台改造成“项目首页 → 项目工作流”的两级信息架构：项目首页负责项目进入与选择，工作流页负责按原 Skill 链逐步执行、查看任务状态和浏览成果物。

## 范围

本次只改造工作台的页面结构、导航状态和步骤工作区，不修改 `skills/`、Skill 锁定机制、Codex 调用协议、项目存储、任务队列、成果物索引或视频模型适配器。

保留原 Skill 流程顺序：

1. 生成大纲：`novel-outline`
2. 生成角色：`novel-characters`
3. 生成美术：`novel-art`
4. 生成剧本：`novel-script`
5. 生成分镜：`novel-storyboard`
6. 成片：视频模型任务，属于工作台最终步骤，不伪装成原始 Skill

角色设定图、场景/道具图和分镜图由 Codex imagegen 在各自所属步骤内按需生成，不单独占用顶层步骤。

## 页面与路由

使用 Hash 路由，避免新增服务端页面路由：

- `#/`：项目首页
- `#/projects/:projectId/workflow`：项目工作流页，默认打开第一个未完成步骤
- `#/projects/:projectId/workflow/:stage`：指定步骤工作区

未知或无效路由回退到项目首页；项目不存在时回退到项目首页并提示项目已不可用。

## 首页：项目列表

首页不展示流程执行面板、成果物详情或任务日志。

空状态只保留：

- 工作台品牌和页面标题
- “还没有项目”的说明
- 唯一主操作“新建项目”

创建项目沿用现有项目 API。创建成功后立即导航到 `#/projects/:projectId/workflow`，不再把创建动作留在工作流侧栏中。

存在项目时显示项目卡片列表，每张卡片至少包含：项目名称、输入资料数量、已完成阶段数量、最近任务状态和“进入工作流”操作。点击项目卡片或操作按钮进入对应工作流页。

## 工作流页

工作流页第一层顶栏包含品牌、当前项目名称、六步导航、任务日志和刷新状态。项目首页与工作流页是两个独立路由，不在顶栏增加设计稿中没有的返回按钮。

六步导航按顺序显示：大纲、角色、美术、剧本、分镜、成片。每个步骤显示序号、名称和状态；当前步骤有明确的激活态，已完成步骤有完成态，被前置条件阻塞的步骤有锁定态。

左侧不再承担流程进度职责。工作流页采用：

- 中央：当前步骤的执行与成果物工作区
- 右侧：当前项目的任务日志与选中任务详情

输入资料、Skill 版本检查和项目基本信息作为当前工作流页的辅助信息，不再通过左侧流程列表表达制作进度。

## 步骤工作区交互

点击顶部步骤只执行导航，不自动调用 Skill。这样切换步骤不会产生重复任务、模型费用或成果物覆盖。

当前步骤工作区包含：

- 步骤标题、对应 Skill、职责说明
- 前置条件和当前可执行状态
- “执行”或“重新执行”主按钮
- 当前步骤任务状态、运行日志入口
- 当前步骤关联成果物列表
- 报告、JSON、Markdown、图片和视频预览

步骤执行按钮继续调用现有 `POST /api/projects/:id/tasks`，不会新增另一套调用链。图片步骤继续要求用户选择归属阶段；成片步骤继续使用现有视频模型选择和 `POST /api/projects/:id/video-jobs`。

## 数据与状态

导航状态由 URL 和内存状态共同维护：

- URL 保存当前项目和当前步骤，刷新后可恢复
- 项目、任务和成果物仍由现有 API 提供
- 进入工作流后加载项目、任务和成果物
- 任务 SSE 事件只更新当前项目的步骤状态、任务日志和成果物计数
- 返回首页不取消运行中的任务，重新进入项目后继续读取服务端状态

## 错误与空状态

- 服务不可用：页面保留可见结构，显示本地服务不可用，不进入不可恢复的空白页
- 首页无项目：只显示新建项目入口
- 工作流无输入资料：步骤导航仍可见，执行按钮按现有 readiness gate 禁用并说明缺少输入
- 步骤无成果物：显示该步骤专属空状态，不显示旧字符图标
- 任务失败：保留失败状态、错误日志和重新执行入口

## 视觉约束

继续使用已落地的原 Skill report 风格：冷灰纸张背景、细线分隔、衬线标题、锈红强调色、Iconsax 免费图标。禁止 Emoji 和装饰性 Unicode 图标。首页和工作流页共享同一套视觉 token，不新增深色卡片或厚重阴影。

工作流顶栏按 Figma `head` 结构实现：64px 高、上下 16px、左右 32px 内边距、白色背景、底部 1px `#8A3324` 分隔线；左侧 `head-left` 宽 352px，中间 `steps` 宽 528px，右侧 `head-right` 宽 202px。品牌组和当前项目组各 164px，中间以 32px 高的 1px 竖线和 12px 间距分隔；步骤胶囊为 68×28px、圆角 24px，步骤间为 20px 宽的 1px 虚线。

顶栏英文眉题、步骤序号和步骤名称使用 `DINish`；英文眉题为 10px/12px，步骤文字为 14px/20px；中文品牌标题和项目名称使用 `Songti TC`，20px/20px。

## 验收标准

- 首次打开 `#/` 时不出现工作流侧栏，只有空项目首页和新建项目入口
- 新建项目后自动进入对应项目工作流页
- 工作流进度只在顶栏显示，左侧不再出现纵向阶段列表
- 顶层步骤只包含大纲、角色、美术、剧本、分镜、成片，图片生成归属角色、美术或分镜步骤
- 点击顶栏步骤只切换工作区，不创建任务
- 点击步骤内执行按钮才创建对应 Skill 任务
- 刷新 `#/projects/:id/workflow/:stage` 后项目和步骤仍能恢复
- 任务状态、SSE 日志、成果物预览和视频任务能力保持可用
- `skills/` 内容、锁定文件和原有全量测试不受影响
